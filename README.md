# 📦 互动小纸箱机器人 (Cardboard Robot)

一个基于 ESP32-C3 的桌面级互动小机器人。不仅能卖萌眨眼，还能追着你的手看，摸摸头还会开心地摇头！

## ✨ 功能特性
- **待机状态**：等大对称的纯线条大眼睛，随机自动眨眼。
- **摸摸头**：手指触摸头顶（TTP223），屏幕显示 `^ ^` 笑眼，并温柔摇头。
- **追手模式**：红外避障模块检测到左右手靠近，眼睛平移，并驱动双舵机云台平滑追踪。

## 🛒 硬件清单 (BOM)
- 主控板：ESP32-C3 SuperMini / PRO MINI
- 显示屏：0.96寸 I2C OLED (SSD1306)
- 舵机：SG90 微型舵机 × 2
- 传感器：红外避障模块 × 2、TTP223 电容触摸模块 × 1
- 供电：多路 DC 电源模块（为舵机提供独立 5V）
- 其他：硬纸板、热熔胶、杜邦线若干

## 🔌 接线说明
| 模块 | 引脚 | 接 ESP32-C3 引脚 | 备注 |
| :--- | :--- | :--- | :--- |
| **OLED 屏幕** | SDA / SCL | GPIO 5 / GPIO 6 | VCC 接 3.3V |
| **左红外模块** | OUT | GPIO 4 | 探测到障碍物输出低电平 |
| **右红外模块** | OUT | GPIO 10 | 探测到障碍物输出低电平 |
| **触摸模块** | OUT | GPIO 2 | 触摸输出高电平 |
| **水平舵机 (Pan)** | 信号线 (橙) | GPIO 0 | **电源(红)必须接外部5V** |
| **竖直舵机 (Tilt)**| 信号线 (橙) | GPIO 1 | **电源(红)必须接外部5V** |
| **共地 (GND)** | GND | ESP32 GND ↔ 外部电源 GND | **极其重要，必须连在一起** |

## 💻 软件依赖
在 Arduino IDE 中，需要提前安装以下库：
- `Adafruit SSD1306`
- `Adafruit GFX Library`
- `ESP32Servo`

## 🚀 如何烧录
1. 按照接线表连接好硬件。
2. 打开 `code/robot_main.ino` 文件。
3. 选择开发板为 `ESP32C3 Dev Module`，选对 COM 端口。
4. 点击上传即可。
